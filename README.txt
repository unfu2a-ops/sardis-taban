سردیس تابان — Mini Project
============================

فایل‌ها:
- index.html
- style.css
- script.js
- assets/

ویژگی‌ها:
- طراحی کاملاً ریسپانسیو
- منوی موبایل
- معرفی کولر گازی، پمپ، پکیج و لوازم خانگی
- دو شماره تماس مستقیم
- دکمه و آیدی اینستاگرام @sardistaban
- آدرس یزد، بلوار جمهوری، نبش چهارراه وکیل، نمایندگی گرین
- دکمه مسیریابی
- بدون فریم‌ورک و بدون نیاز به بک‌اند

برای GitHub Pages:
index.html، style.css و script.js را در ریشه ریپازیتوری قرار دهید.
